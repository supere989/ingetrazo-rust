# Native CAD callback consumer candidate

The native painter freezes backend-neutral callback snapshots and encodes precise CAD together with generic meshes in their original primitive order inside the existing BGRA UI render pass. Apple-family framebuffer-fetch/raster-order-group admission uses the previously native-tested exact byte shader with a BGRA pipeline variant. It adds no intermediate image, readback, extra render pass or per-primitive process handoff. Generic mesh pipeline/buffer bindings are explicitly restored after each CAD callback.

Cold immutable geometry uses two budgeted Metal buffers, cached by immutable geometry ID. Palette conversion is cached by retained Arc identity. A warm unchanged callback has no geometry or palette-byte reconstruction/upload; pose is supplied as uniforms at encoding. Caches admit at most64 geometry/palette identities, with4096 batches per callback and8192 primitives per prepared paint. Clearing a cache cannot free buffers still retained by a prepared frame. Metrics bytes are cumulative logical upload bytes, not a claim of complete driver-memory accounting.

Every prepared callback retains its frozen geometry/palette/pose, native pipeline and buffer owners. Existing presentation owners retain prepared paint until actual GPU completion AND terminal drawable notification, preserving unresolved-owner quarantine. The offscreen diagnostic tests GPU command completion only: it does not prove window presentation or lifetime notification on AppleParavirtual ARM.

`cad_callback_probe --output=FRESH_DIR` executes authored Qt color37/93/157/128 over white, whole64×64 comparison, callback-only rendering, ten warm redraws, pose change with frozen old paint replay, actual vertex admission followed by index admission failure, prior image/ledger preservation, retry and final ledger zero. This candidate crosscompiles; actual native execution remains pending. On devices lacking Apple framebuffer fetch it records explicit unsupported with passed=false; --require-supported refuses. Intel/AMD exact span-compute presentation remains a mandatory unfinished stage, not an approximate fallback or completed backend.

Shared application installation is additionally opt-in via INGETRAZO_METAL_CAD_CALLBACKS=1. It refuses unsupported capability before installation. Existing host presentation/lifecycle failures and all physicalMac/full-world/material/texture/compression/raytracing acceptance remain open. Full nine source-shape native images, DPI/phase/coverage and true shared application presentation are required before promotion.
