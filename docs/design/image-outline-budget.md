# Shared-budget outline pages

The arena has no private byte ceiling. Resources.allocate_buffer reserves actual VkMemoryRequirements.size against the same live VulkanBudget used by world geometry, images, staging and egui. Existing application/heap headroom policy is retained. Required page sizes use checked arithmetic and indexed draw address bounds before allocation.

A free range is reused immediately. New pages prefer one MiB granularity. Only an explicit shared-ledger admission refusal permits recovery: fully empty pages in both vertex/index arenas are retired, the already acknowledged graphics fence collects their allocations, then the exact required four-byte aligned page is attempted. Device errors, unknown completion and driver OOM are not reclassified as budget pressure. Current Resources errors are strings; the recovery predicate matches only the exact three ledger message grammars (including the known allocator Display wrapper), with focused rejection tests. A future typed resource admission error should replace this boundary.

A page is empty only when its entire free extent is coalesced and no Pending/Published/Retired range exists. Retired ranges enter the free list only after the actual completion serial. Pending candidates from uncertain transfers remain owned. No page enumeration is added on unchanged warm frames, and reusable empty pages are not reclaimed during ordinary dirty updates. Actual reclamation counters expose page and logical byte counts separately from existing actual allocation/staging ledger metrics.

Candidate failure retains the old published geometry and pose; there is no silent removal of valid geometry. Exhausted shared budget remains an explicit preparation refusal, with the old frame available. This stage removes the artificial 64 MiB outline ceiling; it does not promise an unlimited physical memory pool or solve all fragmentation/streaming. Hardware admission/readback controls remain follow-ups until separately proven. Metal requires the analogous native budget/range consumer.
