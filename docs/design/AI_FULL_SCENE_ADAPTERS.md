## Reviewed registry and spatial-index prerequisites

The reviewed standalone owner now uses an owner-private shared registry and transaction-local overlays. Fresh integrated acceptance confirms zero-allocation begin at three base sizes; see [registry acceptance](../audits/ai-persistent-registry-root/acceptance.json). The design requirements below remain the contract for production integration. Owner constructor/New/Open/replacement build it once; no unrestricted mutable registry references escape. Each transaction captures document/state/revision and checks it before source lookup. Stale transactions refuse instead of reading newer IDs. Lookups check staged entries then existing entries, retaining exact-key priority and dx/dy/dz neighbour order. Position arithmetic remains Qt float32 as in the source corpus; native imported f64 key quantization remains a separately retained boundary.

Before append/Undo/Redo publication, reserve registry/index updates and compute exact IDs/inverse entries. Failed preparation changes no semantic registry/tokens/history. A replacement marks the old registry stale while held transactions retain its charged lifetime until release. Add a separate retained-registry budget category; staging charges overlays only. Avoid per-script base snapshots or unbounded chain-of-delta lookup. Measure actual varying transactions with large bases: begun-script allocation count, registry scans, shared registry identity, and source-weld cases, not merely no-clone grep.

The registry eliminates BEGIN lookup cloning. A subsequently reviewed reversible spatial delta now avoids full core index rebuilding for private append/Undo/Redo; constructor and replacement remain cold. [Fresh spatial acceptance](../audits/ai-spatial-delta-root/acceptance.json) records 22 owner tests, real allocator failures, original history/weld equality and warm allocation scaling with initial capacity growth reported separately. This API requires exclusive ownership of an unchanged prefix and exact appended tail; it is not a validator for arbitrary mutable Mesh access. Full GUI Scene writers are not yet routed through the private owner, so production activation cannot follow from this standalone change. VM compiler/native costs documented in AI_NATIVE_COST_ADMISSION.md remain blockers. No new dependency fork or production activation is introduced by this design.
