# Optional same-pass annotation stencil prototype

Frozen source `b5ade40bd98ee875d9446b24465d73d2fe0858b8` and binary SHA in archive.json reproduce 28 actual NVIDIA owned-window 800×600 images exactly against the **unchanged** Qt 6.12 original references in annotation-alpha-union. The 24 alpha line cases include alpha 0/1/127/128/230/255, narrow and short lines, and crossing source operations. Four circle/ellipse cases include translucent and tiny geometry. Whole images include the exterior white region. Source remains pinned to 6be29fe437a7cd992d4e079f71720821b25216b9.

Fill and stroke vertex observers capture the actual Qt GL submitted counts and immutable vertex buffer positions. The Rust fill counts 37/77/13/257 and stroke counts 51/123/35/515 match the recorded source coordinates bit-for-bit. This uses the pinned Qt convex cubic fan and bevel stroker arithmetic; it does not replace the original frame oracle.

The attachment is an optional, actual-budgeted S8 image (532480 bytes at 800×600 on this RTX device). Marker triangles use their individual conservative bounding quads and exact source fixed-point sample ownership tests. The source operation composites once through stencil and fixed-function SourceOver. Source operations remain ordered in the existing UI renderpass. Default source activation remains unchanged.

Follow-up batching places immutable per-vertex source records in the **same** vertex-buffer allocation after the unchanged 12-byte vertex ABI. A separate marker shader reads that tail and transforms source points with explicit f32 multiply/add/density operations. Cold marker groups admit contiguous matching gate/bounds records; warm dispatch visits one group rather than every triangle. This preserves the existing two-buffer publication/rollback owner, with actual packed bytes charged to the Vulkan allocation ledger. Record packing uses one bounded fallible byte vector plus an assignment mask, and refuses incompatible shared-vertex metadata.

Temporary marker packing costs 52 bytes per geometry vertex plus one-byte assignment mask; retained GPU metadata costs 40 bytes per vertex in addition to the existing 12-byte vertex ABI. This applies only to the optional stencil renderer. Cached marker-group arrays are included in cold handle CPU accounting. The marker fragment footprint still includes the per-triangle conservative bounding rectangle, rather than a tighter conservative triangle. GPU throughput, tighter cover, broader DPR/pose/cap/style controls, production activation and complete application annotation parity remain OPEN. Lower draw counts alone do not establish the shortest renderer.

Use `scripts/check-annotation-stencil-curves.py` to verify the frozen first checkpoint. The previous alpha bounds failures and ellipse fallback failures remain in annotation-alpha-union. No tolerance has changed.
