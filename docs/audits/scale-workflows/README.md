# Scale controller and app checkpoint

The Rust Scale tool now uses the original grip controller and grab-time transforms for loose geometry, baked groups, placed components and image planes. Ctrl/Shift taps, live preview, cancel, drag release, typed factors/absolute lengths/mirrors, immediate hot retype and relative image history are wired. Warped loose faces autofold only at commit; only a genuinely folded operation retains an additional topology baseline for retype. Placed-only previews update pose revision without invalidating prototype geometry. Warm vertex publication is two passes over captured targets with no scene clone or whole-model lookup rebuild. Shared plain groups propagate geometry/UVW to captured registry, nested and definition owners; axes stay placement-specific.

Actual pinned ScaleTool/History versus native app dispatch: eight base workflows give **74 exact literal states**, with one explicit mirror-registry integrity difference. Three shared-prototype workflows give **30 exact app states**, including ten repeat states for the baked-group control. Together this is ten distinct workflows, **94 distinct exact states** and one explicit difference, not a feature-completion percentage. Ten base and nine shared checker corruptions reject. Seven focused app checks pass. The prior grip controller's 288 exact controls and core autofold proof remain separately scoped.

The source mirror loop updates its registry one vertex at a time. Two exchanged position keys are lost, despite selection still referring to the live face; the next grab reacquires only two vertices. The retained diagnostic records this. Rust publishes target keys in two passes and scales all four owned vertices; the checker requires the correct complete native geometry and records the eight differing source coordinate fields. This is an intentional integrity difference, never normalized into an exact source match.

Every archived file was verified byte-for-byte. Initial source/native output and one Rust test compilation failure are retained.
