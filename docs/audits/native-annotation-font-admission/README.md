# Annotation font admission scope
Sized-face `Cache::stats` records encoded-byte references per sized face. These references may share one Arc and exclude native FT/HB allocation. Resolver backing `FontCache` independently retains up to 16 faces/32 MiB encoded bytes, plus bounded request FIFO bookkeeping; resolution precedes sized-face admission. Neither counter is a total resident allocation bound, and adding the counters double-counts shared encoded ownership. Native library tables/configuration and peak construction allocations remain a separate resource-admission requirement.

Focused production test `resolver_backing_admission_is_visible_when_sized_admission_refuses` gives sized admission a one-byte budget. Resolution refuses sized publication, leaves sized counters zero, exposes nonzero backing ownership, and a repeated refusal performs no new backing load. Existing warm mesh/glyph cache tests pass separately. This is CPU ownership evidence, not annotation pixels or full GPU publication acceptance.
