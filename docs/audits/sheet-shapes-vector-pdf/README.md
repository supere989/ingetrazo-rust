# Direct source shape vector PDF review stage

The native formats painter translates the nine source physical shape recipes directly into vector PDF paths, with source round caps/bevel joins, fill alpha replacement, clip paths, visible stable z order, A4 integer-point media box and source default margin rounded to42pixels at300DPI (10.08points). No screenshot, intermediate raster surface, render process or worker is used. Unsupported visible item painters and sheet borders fail explicitly rather than produce an incomplete sheet.

Actual frozen original `ComposerWindow.export_all_pdf` creates the nine-page original atlas. Independent QtPdf/PDFium parses both atlases and renders whole white-flattened pages. All nine pages match exactly at72DPI. Higher-resolution144DPI remains FAIL: rounded13pixels, ellipse16pixels, arrow8pixels; the remaining six pages match exactly. The stricter failures are retained, and no tolerance is added. Vector coordinate/cubic serialization precision remains under review. Initial ten-point margin failures are retained in `initial-unquantized-margin`.

This is an isolated API stage, not a full export feature or release acceptance. All other source sheet item painters, export UI, PNG/JPEG, full atlas workflows, higher-precision QColor formats and broader page/color/geometry controls remain open. Ordinary full color parsing currently uses the shared8bit raster color parser; full vector QColor precision is not claimed. Same-directory replacement validates all pages before touching the destination; parent-directory crash durability has not been demonstrated.
