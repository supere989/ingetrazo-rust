# Typed append-only mesh journal feasibility

This standalone proof executes eight literal programs through actual pinned original core.ai.run_transactional and genuine RustPython, with Rust callbacks staging edge additions and publishing to real ingetrazo_core Scene.mesh only after successful execution. The journal builds a cold mesh index once per transaction; edge calls do not clone Mesh or Scene. Failure discards unpublished positions/topology. Stale-version publication refuses before mutation. Existing edge proxies retain identity across a failed transaction; failed pending proxies are detached and never rebound when an index is reused. Their cache eviction visits only pending edge IDs.

Source/native topology, changed/failure flags, stdout/expression Edge repr, existing and detached object comparisons match eight controls. Two focused Rust tests cover discard and stale-base refusal; five validator mutations reject. Full traceback bytes remain different because native and original wrapper frames differ. Integer f64 admission failure and initial proxy identity failure are retained, not counted as acceptance.

The facade supports only bounded unpainted edge append programs. It is not enabled in production run_python. Attribute mutation, faces, materials, layers, component/context/history, all imports, deadline/fuel cancellation and full atomic allocation failure remain OPEN. Publication currently assumes successful Rust allocation; it has no claimed allocation-failure journal proof. Scene.version/source undo details are not covered. Native Mesh weld keys use ties-away/i64/exact-cell while original uses ties-even/arbitrary ints/neighbour probes; boundary proof/correction is required separately. No general source Mesh/Qt compatibility or whole-document atomicity claim.

The existing language proof was rerun after extracting its shared execution helper; parsed results unchanged. The first real core build required the frozen submodule (missing include_str resources); initialize with the retained original reference. No broad workspace run or GPU/provider activity occurred.
