# Nested import source contract

Frozen root-acquired original observations: 15 cases, 105 chronological states. Source was captured once through actual original loaders, SnapshotImport/History and Viewport context entry/Finish. No native execution or renderer claim is included.

`source-records.zip` contains five import files, fifteen input IGZ documents, fifteen original saved IGZ documents, the typed original states and source stdout/stderr. `source-manifest.json` authenticates every member, unchanged source commit, helper and relevant original implementation files. Every archived member was compared bytewise with its retained raw input before this freeze. Raw records remain at `/tmp/ingetrazo-nested-import-proof` for integration replay.

Contexts are root, transformed container and transformed shared leaf. Each imports unnamed OBJ, single named OBJ, two-part OBJ, tagged DXF and layer-zero DXF. Phases are before, import, Undo, Redo, Finish, Finish Undo and Finish Redo. Source group/list and active/loose mesh observations include ordered history depths, geometry, transforms, layers and units.

The actual OBJ loader writes one piece (including a named sole piece) into the active mesh. Multiple pieces append one document-root container with named child groups. DXF always appends new document-root groups; layer zero uses the file stem, and an existing same-name group is preserved. Import is one SnapshotImport command and does not Finish the active context. This archive is an implementation authority, not native acceptance evidence.

The naming addendum authenticates five loaded/repeated-name states and six Blender-name cleanup controls, including the first reader-helper failure. Current reservation covers source automatic ASCII `Group N` names; Unicode decimal-spelled manually authored names are not yet reserved. Exhausted u64 automatic names refuse before document publication.

New import kind preservation owns only authored `component` and `xform` JSON fields and their baseline; it never serializes the imported geometry to seed metadata. Actual original-reader comparisons require all fifteen cases and compare group kind/placement, face/edge layers and genuine shared Mesh identity in addition to geometry. Root publication prepares checkpoints before assigning owners, but cold candidate/history snapshots remain whole-owner copies. OBJ piece bucketing is linear in entities, and fresh DXF groups use a local curve counter. MTL, source fusion/orientation/smoothing and linked-copy normalization of newly imported containers remain P22 gaps.
