# Composer PDF UI integration

Composer now exposes current-sheet and all-sheet PDF save actions through the normal native save dialog and reports success/error. Controller prepares every page before atomic writer save. Meaningful regression exports a supported page, then refuses an atlas with unsupported visible view/title painters and an invalid sheet index while preserving the original destination bytes. GUI compilation and regression pass.

Actual pointer/dialog replay remains pending. Default sheets contain unsupported view/title painters and therefore report errors; this stage does not close full export parity or failed-frame atlas continuation semantics. No silent omissions, raster intermediate or subprocess introduced.
