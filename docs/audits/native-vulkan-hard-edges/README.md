# Cached direct-GPU hard edges

Original GL source emits 1px hard lines after the surface passes, including Wireframe even when the Edges toggle is false. XRay first draws opaque face depth without color (excludes colored transparent/front-only glass), then GREATER depth edges faded 60% toward background, then normal LEQUAL edges. It clears depth after edges, preserving stencil for later overlays/cut contours. Native pipelines reuse cached world-space hard endpoints and opaque face ranges, with no per-frame geometry copy, CPU projection, depth sort, or scene traversal. Each cached edge costs 24 additional position bytes. Native submission draws two instanced endpoint vertices per edge. Soft silhouette/profile and dashed Back Edges remain separate open requirements.

Feature-advertised shaderClipDistance is enabled explicitly in native/headless device creation. The edge vertex shader clips before rasterization; the edge fragment shader does not discard fragment centers, which would lose kept partially covered endpoint samples. When the feature is unavailable a direct GPU endpoint-clipping shader is selected, retaining valid models. `INGETRAZO_FORCE_MANUAL_EDGE_CLIP=1` is an engineering fallback control, evaluated at pipeline creation, not per frame.
