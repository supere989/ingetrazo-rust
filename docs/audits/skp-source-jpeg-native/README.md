# Native source JPEG decoder
Scoped Rust opt-in with pinned IJG/libjpeg-turbo3.2.0 law; stock zune SIMD/default policy unchanged. Full decodedRGBA and sixteen average pixels exact for four real Capilla JPEG assets. Default-path SHA unchanged for allfour.
Actual Qt writer32 and independent ImageMagick SOF-verified444/422/440/420 baseline/progressive64 controls exact, including odd/tiny dimensions. Five malformed/budget negative controls preserve previous output; six PNGalpha controls exact. Initial IDCT-only failures and vertical MCU-padding boundary failures retained.
JPEG metadata unused by pixel decoder is skipped in-place; APP14 remains parsed. Header reserve admission precedes parse; dimensions/work precede decoded buffers. PNG decoder receives limits before header decoding, and reuses that decoder. API limits are configurable; caller must connect budget policy. Large/streamed assets and native ARM/Windows runtime remain required, not permanently excluded. The source correctness transform is scalar only; no optimized cold SIMD claim.
