Required stages remain open. Start with pinned gondola_v20 (recursive shared placement/material/layer inventory already exact) and capilla_quiroz_v17 (also 26 imported dimensions). Both stages below must use the same original SKP SHA, native source/executable SHA and output IGZ SHA. Keep complete imported group/material/layer/annotation and explicit other-record inventories beside the images; never replace these checks with triangles alone.

1. Isolation stage: actual original SKP import and native-import IGZ reopen, both painted by the frozen Qt/OpenGL Viewport. Freeze a numeric orthographic isometric camera, target/distance/roll, physical 800x600 extent, sample count, background, edges and Shaded style in a protocol. Capture each readable fresh framebuffer only after actual paint. Strict complete-image comparison and separate object visibility regions; black/empty image and altered geometry negatives. This isolates imported document semantics and is not native renderer proof.
2. Required native stage: load the identical native imported Scene into production native Vulkan World, using the frozen camera/style/extent and actual GPU adapter. Reference must be original Qt/OpenGL on the same NVIDIA adapter (retain Mesa separately). Readback/capture only the diagnostic target or owned window, retain device/vendor, shader/source/executable hashes, complete image and source inventory. Native geometry/cache admission, warm zero uploads, budget rollback and unchanged previous image/owner controls must remain in scope. Native camera/style/context invalidation is required. Any full-image failure remains a failure without tolerance adjustment.

Camera parameters must be authored and frozen before comparison; no post-render alignment or palette fitting. Orthographic iso plus a second asymmetric view prevents front-only coincidence. Materials/textures/annotations are retained even if the initial style tests their shaded representation; texture/style/section/billboard and native application workflows remain separate required stages. A Qt-only pass cannot close rendered import parity. Physical Mac/Metal and other binary eras remain open.
