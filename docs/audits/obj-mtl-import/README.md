# External OBJ/MTL Import

Original-supported material subset: newmtl/Kd/map_Kd. Opacity/shininess/ambient/specular tags are ignored by original and by this path. Missing MTL/images fall back to unpainted/Kd. Map options are stripped, quoted/spaced names and foreign Windows/POSIX basename fallback are supported. Materials paint both sides; default cream rounded to four decimals stays unpainted. Complete UV assignments use the source strongest edge-pair affine fit and gradient tile sizes; incomplete or degenerate fits keep planar texture.

Only newly imported points use the existing source Qt construction law. Legacy APIs and native f64 geometry are untouched. Resolved used image bytes are deduplicated and prepared before selecting/cloning an owner, then moved into original-compatible embedded member keys. Root publication prepares every checkpoint resource owner before assignment; resources and geometry/history are published together. Actual fifteen-case source corpus covers root/nested imports, material recipes/options/path behavior, malformed sidecars, and saves. Images are compared by exact bytes and file name; source external path and native owned-member representation remain distinct. No new GPU or complete P22 promotion. Geometry fusion/orientation/smoothing and linked-copy normalization remain prior gaps. Native nonfinite recipes/affine overflow are refused before mutation rather than serialized as invalid numbers. Cold candidate/history/checkpoint clones remain explicit ownership costs, not a total-memory bound.

Consumer: context_document_lifecycle DIR --obj-mtl. Original reader: scripts/reference-obj-mtl-reopens.py DIR. Strict checker: scripts/check-obj-mtl-import.py DIR.
