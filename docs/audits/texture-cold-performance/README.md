# Bounded cold Vulkan texture preparation

Runtime base: `98a86ea790e34a6b6ccb1d8e9e99f939b41b6814`. Harness: `b9cfbf64`; geometry scatter: `65223332`; bounded PNG overlap: `22f56006aa22318c6cac414f770997272bf5e1c5`.

Full `World::set_scene` elapsed CPU time is measured from immediately before invocation until successful return. Each sample owns fresh World/cache/resources; two iterations on the same persistent device/driver discard the first as driver warmup. World/pipeline construction, fixture creation, rendering and readback are outside the timer in both binaries. Ten sequential processes alternate baseline/candidate and reverse order every other pair. Root and document agent compilers were terminal and held throughout the final window. Both binaries use the same unoptimized dev profile, debug0/incremental0; these are bounded actual runtime measurements, not release-build or universal GPU throughput claims. No GPU timestamp/frequency measurements were taken.

Large median improves 38.3%; four of five paired large samples improve. Ranges overlap. Small timings do not establish a strong benefit. The earlier geometry-batching-only candidate failed to improve timing: small6.224→7.498ms and large48.161→51.664ms; all raw runs are retained under `batching-negative/`. Its five geometry buffers total1080bytes. Eliminating four fence waits alone was insufficient; large serial PNG decode dominated. The final candidate uses one native scoped worker plus the caller for cold, uncached, embedded PNG assets only. At least two unique assets of >=512KiB decoded output are required. Selected decoded output totals <=8MiB. Larger assets/external files/JPEG/single assets keep the existing serial decoder, preserving supported admission. No worker starts on unchanged frames or published cache hits. The worker owns no GPU handles; join completes before GPU image admission. Full decoder validation, pixel conversion, mirror, BC7 encoding, mip generation and shader sampling are unchanged. `decode_ms` sums per-image worker durations and is not a wall-clock phase when overlap is active; only `cold_set_scene_ms` is comparable end-to-end.

Geometry scatter uses existing finite-fence `Resources::upload_many`, retaining converted geometry up to8MiB plus one indivisible asset. It avoids another packed CPU copy. Destination IDs are reserved before allocation and remain in the unpublished candidate for rollback. Draw and contour order stay unchanged. Existing uncertain-completion quarantine remains authoritative; this batch does not re-prove device-loss handling. PNG overlap retains <=8MiB of output plus existing bounded decoder scratch (at most two active decoders); it does not claim the output limit bounds total allocator/scratch memory. Encoded assets remain borrowed. Geometry/image staging stays <=8MiB. Cumulative buffer allocation increases608bytes in these fixtures; final resident image/staging bytes are unchanged. Transfer submissions7→3 small and8→4 large; images5, BC7uploads1, generated mip levels26/40, base-image upload bytes315456/8388672 are unchanged.

All40 final benchmark rows (including warmups) have identical full RGBA hashes by set, zero warm extra transfers and finalledger0. Small rows additionally assert the existing actual original NVIDIA near image byte-for-byte inside the binary. Final controls reproduce both existing original near/far whole images, actual image-budget refusal with old frame/entries/ledger preservation and retry,20warm updates with no extra uploads,17MiB GPU base readback with three bounded staging chunks, completed retirement and ledger0. No original GPU frame was recaptured. Historical odd-size source GL mip rounding failures remain open; no mip algorithm changed.

Executable hashes remain provenance, not claims that deleted binaries are available. Large authored assets are deterministic fixture inputs and their encoded hashes are identical between binaries; they are compared to the frozen native baseline, not newly claimed original Qt references.

Read-only checker: `/tmp/ingetrazo-parity-python/bin/python scripts/check-texture-cold-performance.py`. Requires NumPy/Pillow. It verifies all93 raw digests, ten processes per timing series, four rows each, whole-image controls, source/encoded/binary identity, resource counts, bounded staging, warm/ledger controls and four missing/mutation negatives. No timing tolerance or fitted pixel threshold is used. Timing results are reported rather than forced to pass a speed threshold.

Replay uses the retained transport scripts under `transport/` after extraction. It runs direct Vulkan on actual RTX5090 in a disposable read-only CDI container, sequentially and with finite subprocess cleanup. No process/texture wrapper exists in the production render path.
