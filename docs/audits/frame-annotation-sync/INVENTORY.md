There are two separate source paths. Anchored sheet records mutate derived page geometry during ComposerWindow._rebuild_canvas via _reproject_anchored_cotas (composer.py11726). Model annotations are instead projected into immutable frame-local overlay tuples by compute_annotations (9578), cached separately and painted by _paint_annots_mm (512). Their records remain model-owned. A frame can carry both paths.

Sheet cota, primary label and elevation anchors reattach to the nearest current source snap world point only while the old projected anchor lies within the frame plus 0.5 mm. World tolerance is min(2.5×scale/1000,0.5 m), and NumPy argmin preserves first-point ties. Snap arrays come from actual HLR endpoints/midpoints for small parallel fixtures; perspective uses the fast projected endpoint ordering. Cota position/extent/scale update; primary label text position stays fixed; elevation preserves its relative slide and reads anchored world Z minus datum. Extra label leaders only reproject their authored world point and never nearest-resnap. Missing frames preserve stored anchors rather than clearing them. None of this adds a composer Undo command.

The overlay always includes draped GeoPath polylines. Closed paths append the first point. Optional chainage marks and section traces precede the annotation opt-in gate. Dimensions use current model line points, global ends style, value formatting and readable text rotation. Text labels project anchor and separately narrowed QVector position, split lines and place each text on the side away from its anchor. Hidden entity layers are filtered; sections have their own literal source iteration and face-on/extent gates. There is no per-dimension mesh occlusion test in compute_annotations: the paper halo overlay remains distinct from viewport depth visibility.

Projection uses the actual source frame camera, standard/saved views and per-frame roll. Parallel projection preserves scale arithmetic; perspective divides by clamped depth and bounds off-page coordinates. _with_frame_camera restores camera, layers, section/style, geographic visibility and shadows; those restoration observations are part of the contract. Snapshot group-hidden state is not silently added to this promise beyond actual code behavior.

Frame properties and body movement use actual Qt ingress. Model movement uses original MoveVerticesCommand through viewport History, preserving command ownership and Undo/Redo; this does not claim model pointer acquisition. Dimension-style and layer fixture publications are explicitly identified. Creation uses the real cota frame-snap path; generic label/level creation is not claimed to acquire anchors because its current source finish routine clears hit_a first.

The contract freezes eight cohesive cohorts before capture. It records full sheet records, model records, source overlay tuples, source page/world snap arrays, separate model/composer history and actual original saves/readers. No output is an invented mathematical oracle. Physical images, specialized handles, chained dimensions and high-edge-budget fast-path admission remain separately bounded acceptance work. Source errors and signed-zero/f64 observations will be retained exactly.
