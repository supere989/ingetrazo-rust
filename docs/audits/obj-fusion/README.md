# OBJ fusion/orientation/smoothing

Source branch law: editable single-piece <=400 uses run_stitch seeded merge (dominant painted contributor, not a material boundary gate), outward orientation, explicit smoothing groups only. Multipart or >400 reference geometry uses material/UV-compatible fusion, irregular-region fallback, explicit smoothing groups then same-material abs(normal dot)>.85 auto smoothing. _s is temporary and must be removed before publication/save. Piece names and isolated ownership remain the accepted typed-plan policy.

The new finite source controls are twelve cases/sixty states. Existing MTL/nested sources are not recaptured. Closed reversed cube root/leaf, explicit versus hard smoothing, reference patch/hole/nonmanifold/duplicates/paint boundary/auto smoothing, and >400 grid test the missing branches. Allocation-dependent undirected editable open-sheet trace winding remains an explicit source boundary; no pixel or complete P22 promotion.

Implementation owns only unpublished parsed/candidate geometry, with adjacency union, region boundary trace, x-indexed scoped station candidates, queued valence-two collapse, and one derived edge rebuild. No extra whole Scene clone. Existing native f64 and unrelated entity data/tokens have a separate focused protection control; malformed imports must retain document/history.
