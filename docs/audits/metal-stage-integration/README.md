# Direct native Metal stage integration

Billboards now use the same cold source geometry packet as Vulkan. The Vulkan camera-admission wrapper preserves its Qt camera snapshot. Four existing packet controls pass after extraction. Metal stages immutable camera-facing vertex buffers, reuses source texture images across camera movement and Hide/Unhide, and encodes in the existing World pass after ordinary transparency and before edges. Bitmap and mesh runs retain per-placement texture/solid ordering, forced hard cutout, literal unlit solid colors and live section clipping. Ordinary World geometry and billboards share identical image owners, including first cold publication. The native consumer checks warm reuse, camera-only ordinary/image upload counters, hide/restore, allocation refusal, final ledger release and one-upload shared image ownership. Actual native GPU outcomes remain pending.

Two independent reviewers checked source order and frame retention. Both identified the reused-Adapter foreign-context gap; cached billboard and section owners now validate the retained World device/queue/budget identity. Idle targets of the wrong stencil format are retired while pinned frames survive. Source stencil fill marks clipped backface geometry, draws the cached cap before transparency, then leaves depth for annotations. Section cut contours remain open; the ten-scene checker requires every source RGBA pixel and does not relax failures to a coverage threshold.

The integrated Apple ARM Rust metadata check first caught a retained Objective-C function coercion in the new stencil pipeline; explicit local owners fixed it, and the focused check now passes. Both logs are retained. This is not Apple SDK/MSL/GPU proof. The native Apple jobs build/run the actual consumers. The PNG comparator reuses bounded standard-library decoding; all ten source PNGs were checked against exact Qt RGBA output without installing Qt in native CI.

Intel's strict annotation sample-pattern policy is unchanged. Pre-admission Metal diagnostics and a native CGL resolve witness record actual platform behavior; their observations must be correlated to the same device before any production selector change. No CPU occlusion fallback or lower sample-count workaround was introduced.

Focused repair branches skip unrelated CAD/process controls, and new native probes run independently after a successful build so an earlier stage failure does not erase later evidence. The stable integration branch retains its complete CI matrix.
